# 接口文档

## 1. 概述

- **基础 URL**：`http://localhost:8000/api`
- **数据格式**：JSON
- **字符编码**：UTF-8
- **认证方式**：暂未启用（生产环境建议增加 API Key 鉴权）

## 2. 通用响应格式

### 2.1 成功响应

```json
{
  // 业务数据
}
```

### 2.2 错误响应

```json
{
  "detail": "错误描述"
}
```

### 2.3 HTTP 状态码

| 状态码 | 含义 |
|-------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 404 | 资源不存在 |
| 413 | 文件过大 |
| 500 | 服务器内部错误 |

## 3. 教材管理接口

### 3.1 上传教材

**请求**

```
POST /api/textbooks/upload
Content-Type: multipart/form-data

file: <File>
```

**响应**

```json
{
  "textbook_id": "uuid",
  "name": "高中生物 必修一",
  "status": "parsed",
  "message": "成功解析 6 个章节，58000 字"
}
```

**支持的文件格式**：PDF / DOCX / MD / TXT

**文件大小限制**：500MB

### 3.2 获取教材列表

**请求**

```
GET /api/textbooks
```

**响应**

```json
{
  "total": 7,
  "textbooks": [
    {
      "textbook_id": "uuid",
      "name": "高中生物 必修一",
      "file_format": "pdf",
      "file_size": 12345678,
      "status": "parsed",
      "total_pages": 200,
      "total_words": 58000,
      "chapters": [...],
      "upload_time": "2026-05-10T10:00:00"
    }
  ]
}
```

### 3.3 获取教材详情

**请求**

```
GET /api/textbooks/{textbook_id}
```

### 3.4 删除教材

**请求**

```
DELETE /api/textbooks/{textbook_id}
```

## 5. 整合操作接口

### 5.1 启动跨教材整合

**请求**

```
POST /api/integration/start
Content-Type: application/json

{
  "textbook_ids": ["uuid_1", "uuid_2", "uuid_3"]
}
```

**约束**：至少需要 2 本教材

**响应**

```json
{
  "result_id": "uuid",
  "original_total_words": 350000,
  "integrated_total_words": 98000,
  "compression_ratio": 0.28,
  "decisions_summary": {
    "total": 280,
    "merge_count": 45,
    "keep_count": 200,
    "remove_count": 35
  },
  "graph_data": {
    "nodes": [...],
    "edges": [...]
  }
}
```

### 5.2 获取最新整合结果

**请求**

```
GET /api/integration/latest
```

### 5.3 获取整合决策详情

**请求**

```
GET /api/integration/{result_id}/decisions
```

**响应**

{

## 6. RAG 问答接口

### 6.1 建立向量索引

**请求**

```
POST /api/rag/index
Content-Type: application/json

{
  "textbook_ids": ["uuid_1", "uuid_2"]
}
```

**响应**

```json
{
  "message": "Indexed 1250 new chunks",
  "status": {
    "total_documents": 7,
    "total_chunks": 1250,
    "total_textbooks": 7,
    "embedding_model": "BAAI/bge-small-zh-v1.5",
    "index_size": 1250
  }
}
```

## 7. 多轮对话接口

### 7.1 发送对话消息

**请求**

```
POST /api/dialogue/chat
Content-Type: application/json

{
  "message": "为什么要合并白细胞和 leukocyte？",
  "session_id": "uuid"  // 可选，首次对话不传
}
```

**响应**

```json
{
  "session_id": "uuid",
  "message": {
    "message_id": "uuid",
    "role": "assistant",
    "content": "因为这两个名词指代同一概念...",
    "intent": "explain_decision",
    "metadata": {
      "actions": [],
      "graph_updated": false
    },
    "timestamp": "2026-05-10T10:35:00"
  },
  "actions_taken": [],
  "graph_updated": false,
  "updated_graph_id": null
}
```

### 7.2 修改决策示例

**请求**

```json
{
  "message": "取消合并：白细胞和 leukocyte",
  "session_id": "uuid"
}
```

**响应**

```json
{
  "session_id": "uuid",
  "message": {
    "content": "已取消合并：白细胞...",
    "intent": "modify_decision"
  },
  "actions_taken": ["已取消合并：白细胞"],
  "graph_updated": true
}
```

### 7.3 获取会话历史

**请求**

```
GET /api/dialogue/session/{session_id}
```
