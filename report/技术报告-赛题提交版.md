# 学科知识整合智能体技术报告（赛题提交版）

## 一、项目目标与约束

本项目面向“7 本同学科教材知识整合”任务，核心目标是：

1. 在保证教学完整性的前提下，将整合结果压缩到不超过原始教材体量的 30%。
2. 支持知识图谱可视化、跨教材语义对齐、整合决策解释与教师反馈迭代。
3. 提供带来源引用的 RAG 精准问答能力。

关键约束：
- 压缩比口径以教材总字数为分母。
- 每条整合决策需可解释（merge / keep / remove）。
- 问答必须给出可追溯来源（教材、章节、页码）。

---

## 二、系统架构

系统采用“前后端分离 + 专门 Agent 协作”架构：

- 前端：Vue 3 + Element Plus + Cytoscape.js
- 后端：FastAPI（异步任务 + 进度轮询）
- 语义层：Embedding + LLM 双阶段对齐
- 检索层：向量检索 + BM25 混合检索 + Rerank

模块分工：
1. 文件解析模块：支持 PDF / DOCX / MD / TXT。
2. 知识提取模块：章节级提取知识点与关系。
3. 图谱构建模块：单教材图谱节点/边构建。
4. 图谱整合模块：跨教材对齐、决策、压缩控制。
5. RAG 模块：索引构建、查询、引用输出。
6. 对话模块：教师反馈驱动决策修正与图谱更新。

---

## 三、核心技术设计与论证

### 3.1 跨教材对齐：Embedding + LLM 双阶段

采用两层策略：
- 第一层（Embedding）：快速筛选高相似候选对。
- 第二层（LLM）：判断语义是否真正等价。

原因：
- 只用 Embedding：快但误判多（“相似”不等于“等价”）。
- 只用 LLM：准确但成本高、速度慢。
- 双阶段折中：在成本可控下提升等价识别准确率。

### 3.2 压缩比达标机制（≤30%）

压缩策略分三步：
1. 先合并重复知识点（MERGE）。
2. 保留独有与核心知识点（KEEP）。
3. 若仍超目标，按重要性删除低价值节点（REMOVE）。

删除优先级：
- 优先删除 example / application；
- 再删除低频且非核心类别；
- 保护 theorem / definition 和高频节点。

该策略可在保证教学主干不受损的前提下，硬性满足目标压缩比。

### 3.3 RAG 精准问答与引用

Pipeline：
1. 分块：600 字窗口 + 100 字重叠；
2. 检索：向量检索与 BM25 并行；
3. 融合：RRF 融合候选；
4. 排序：Rerank 重排；
5. 生成：LLM 输出答案并附引用。

引用输出规范：
- 必须包含教材名、章节信息、页码（可得时）。
- 前端展示为“回答 + 引用来源”双区域，便于教师核验。

## 四、关键实现结果

### 4.1 压缩比能力

系统已实现可配置目标压缩比（前端滑块 + 后端参数校验 + 强制执行）：
- 前端支持 10%~30% 目标值调节；
- 后端对 target_ratio 做 0.01~1.0 合法性约束；
- 以教材总字数为分母计算 compression_ratio。

### 4.2 工程可用性

- 上传、图谱构建、整合流程使用异步任务，支持进度查询。
- 整合结果返回：压缩比、目标值、知识点保留统计、决策摘要。
- 对话反馈可触发整合决策修改，形成迭代闭环。

### 4.3 前端体验优化

已完成统一设计语言升级（ChatGPT 风格）：
- 全局设计变量（颜色、间距、圆角、阴影）统一；
- 教材管理、整合面板、RAG、对话面板风格一致；
- 信息层级更清晰，核心指标（压缩比、保留率、决策分布）突出。

---

## 五、评测与质量

基于项目内 benchmark 设计（30 题）观察到：
- 混合检索优于单路检索；
- 混合 + Rerank 在召回与答案质量上最佳；
- 中高难跨章节问题仍有优化空间。

工程质量控制：
- Pydantic 模型约束 API 输入输出；
- 关键流程日志可追踪；
- 决策理由可解释、可审阅。

---

## 六、局限与下一步优化

当前局限：
1. 部分跨教材“等价但表述差异大”场景仍依赖 LLM 稳定性。
2. 合并数量（merge_count）受阈值和数据质量影响较大，需进一步调优。
3. 超长教材与扫描版文档在解析效率与质量上仍有提升空间。

优化方向：
- 自适应相似度阈值与领域词表增强；
- 更强 reranker 与多查询重写；
- 增量图谱更新与缓存策略；
- 完整线上 benchmark 自动评测流水线。

---

## 七、结论

该系统已完成赛题要求的关键能力闭环：
- 跨教材知识整合（可解释、可迭代）
- 目标压缩比控制（≤30%）
- 带引用 RAG 问答
- 可视化交互与教师反馈修正

整体方案兼顾可用性、可解释性与工程落地性，具备进一步扩展为生产级教学知识整合平台的基础。
